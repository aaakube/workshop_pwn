# Introductory workshop: stack buffer overflow (at a fast pace)

> Disclaimers:
> 1. this readme is mostly generated by claude Sonnet 4.5 based on my slides
> 2. Some challenges are directly taken from pwn.college, which is a great resource for learning pwn.

A condensed course covering the basics needed to understand and exploit a simple stack buffer overflow on Linux x86-64.

The goal of that workshop is to give to security folks a way to understand what we mean when we speak about memory corruption vulnerabilities such as stack buffer overflow and tries to remove the magic behind it. This is (very) far from being a comprehensive course on vulnerability research.

**What we'll cover**
- A simple stack buffer overflow on Linux
- Enough assembly / shellcode concepts to follow along
- What a running program actually looks like in memory (a "process")
- The stack, and how stack frames are built
- A quick note on ASLR, NX, and PIE (the mitigations we're *not* dealing with yet)
- Four labs of increasing difficulty: https://github.com/aaakube/workshop_pwn

**Setup**: Linux (with ASLR disabled for these labs), Python, and GDB.
